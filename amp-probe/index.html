Fender amp check

This page helps the maneline project make Fender amps work with free software. It connects to your amp over Bluetooth, asks it what it can do, and puts the answers into a report that you can check and then send. It takes about three minutes.

0 Before you start

  1. Use Chrome, Edge or Chromium on a Windows, Mac or Linux computer, or Chrome on an Android phone or tablet. iPhone, iPad, Safari and Firefox can't talk to Bluetooth amps from a web page.
  2. Switch the amp on. Make sure its Bluetooth is on.
  3. Close the Fender Tone app on your phone or tablet, or switch their Bluetooth off. The amp talks to only one app at a time.
  4. Keep the amp close to the computer or phone.
  5. Linux, if this computer is paired with the amp for audio: the browser would use the audio link, which has no control service; that is on the amp's Bluetooth LE link. After you choose the amp in step 1, the page shows a few lines to run in a terminal first, and step 5 shows how to undo them. Nothing to type: the lines find the amp by its name.

Your privacy: this page sends nothing anywhere. It only talks to your amp. At the end you see the whole report and decide whether to send it. The report leaves out the amp's Bluetooth address, Wi-Fi names and addresses, and who made your presets.

Want to read this page first, or use it without internet? Download this page, then open the file in Chrome or Edge on your computer. It works the same.

1 Connect

Click the button, pick your amp in the list that opens, then click Pair or Connect.

Linux: before connecting, run these lines in a terminal (copy, paste, Enter; any shell, they run in bash). They look for "" among this computer's paired devices (or for a paired Fender amp, if the name differs), save its current Bluetooth setting, disconnect it and let Bluetooth use its LE link. If no amp is paired with this computer, they change nothing and say so. Step 5 shows the lines that put it back.












2 Reading from the amp


This only reads. Your amp doesn't change.


    

    


    

    3 Short control test (you can skip it)
    

    The page switches your amp to another preset for two seconds and back, and then turns
one knob (such as gain) a little and back. Nothing is saved: your presets stay as
they are. If you have changed the current sound without saving it, the test is skipped
so your changes are kept.
    

    With a guitar plugged in you can hear the change, even if the amp's display stays dark.
If you can't tell, answer "Not sure": the page reads the values back from the amp anyway.

    5 Check the report, then send it
    

    This is everything the report contains. Please read it. If you find something you don't
want to share, you can stop here, or edit the saved file before you send it.
    

    

    

    




    Then send it, in one of these ways:
    

    

    By email: "Send by email" copies the whole report and opens your email program
with the address and subject filled in. In the email, paste the report where it says so
(Ctrl+V, on a Mac ⌘V), or attach the saved file, then send. If you write email in Gmail in the
browser and no email program opens, use "Gmail in the browser" instead: it opens Gmail's new message
the same way.
    

    On GitHub (needs a GitHub account (free)): "Report on GitHub" also copies the report and opens a
new issue. Paste the report into the text box, or drag the saved file there.
    

    




    

    

    Linux: put Bluetooth back as it was, if you ran the lines from step 1. These read what
those lines saved, set the amp's Bluetooth setting back and reconnect its audio link. If you ran
nothing, they just say so.
    

    


    

    


    

    Optional: send even more details
    

    If we ask you to, and you are fine with installing Python, a small program
records a few things the browser can't see: more Bluetooth details, and how the amp shows
up as a USB or Bluetooth audio device on your computer. It reads the amp in the same way as
this page, makes the same kind of report for you to check, and sends nothing by itself.
    

      

    1. Install Python 3.9 or newer from python.org
(Windows: tick Add python.exe to PATH in the installer).
      2. 

    2. Download the program (fender_amp_probe.py)
into your Downloads folder.
      3. 

    3. Open Terminal (Mac, Linux) or Command Prompt (Windows) and type these lines,
pressing Enter after each:

      Windows:  cd Downloads
          py -m pip install bleak
          py fender_amp_probe.py

Mac:      cd Downloads
          python3 -m pip install bleak
          python3 fender_amp_probe.py

Linux:    cd ~/Downloads
          python3 -m venv amp-venv
          amp-venv/bin/pip install bleak
          amp-venv/bin/python fender_amp_probe.py
      
On Linux, Python is usually installed already. If the amp plays audio from this computer
over Bluetooth, the program offers to disconnect that first.
      4. 

    4. Answer its questions. It saves the report on your Desktop and offers to send it,
like this page.
